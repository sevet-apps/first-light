# Intro film — script and edit plan (≈30–34 s)

Tone: an intimate, slow, low and velvety female narrator counting from one to ten — each number a beat of the film, each line a small promise of the adventure ahead. Long breaths between items, a faint smile on the last line. Structure inspired by festival-racing game intros (a numbered list of reasons), text is original.
